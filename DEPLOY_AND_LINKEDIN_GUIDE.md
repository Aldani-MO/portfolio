Add the public portfolio URL as a LinkedIn Featured link or profile website. Suggested title: Mohamed Aldani | Developer portfolio. Suggested description: Selected work in web development, transit systems and security, with interactive demos in English and Arabic.

The Vercel project is mohamed-aldani-portfolio under mohamed-aldani. The GitHub repository is connected. Future pushes to main should build and publish automatically. Run pnpm build and pnpm test before pushing.

The production URL is public and does not require visitors to sign in. The deployment-specific preview URL may have Vercel authentication enabled; share the production URL above.

Contact currently uses direct email. To enable server-delivered messages, add RESEND_API_KEY and CONTACT_FROM_EMAIL in Vercel with a verified sender, then redeploy. Keep both values out of Git.

A custom domain is optional. Add a domain in Vercel, follow its DNS instructions and set NEXT_PUBLIC_SITE_URL to its final HTTPS origin before redeploying. The site otherwise derives its canonical URLs from Vercel's production domain.

The social preview PNG is generated at /opengraph-image. If LinkedIn caches an older preview, use LinkedIn's Post Inspector to refresh it.
